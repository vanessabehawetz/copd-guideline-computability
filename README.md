# Assessing the computability of COPD guideline recommendations using BPMN and DMN: An exploratory case study
This is the supplemental data repository for the publication "Assessing the computability of COPD guideline recommendations using BPMN and DMN: An exploratory case study". For this study sections of the German National Disease Management Guideline for Chronic Obstructive Pulmonary Disease (NVL COPD) have been analyzed. This repository contains Business Process and Modelling (BPMN) and Decision Model Notation (DMN) artefacts as well as picture representaions that reflect the insights gained from reviewing and translating recommendations of sections within Clinical Practice Guidelines.

## Structure
* Supplementary_S1_Benchmark
* Supplementary_S2_modelling_and_interpretation_protocol
* Supplementary_S3_BPMN_models
* Supplementary_S4_DMN_tables
* Supplementary_S5_evaluation_protocol

## Disclaimer
This repository is part of a publication submitted for review to the MIE Conference 2027.

## Contents
The following sections of the NVL COPD have been represented:
* (A) E-Cigarette cessation 
* (B) Tobacco cessation
* (C) Medication exacerbations during tobacco cessation
